## 🚀 Featured Projects

### 🛍️ [ShopPilot Mobile](https://github.com/dominhtri055/shoppilot-mobile)

Cross-platform merchant operations dashboard built with **React Native, Expo, TypeScript, and Supabase**.

- Authentication, session persistence, email confirmation, and password recovery
- Product CRUD, image uploads, inventory management, and filtering
- Order management, fulfillment workflows, and refunds
- Revenue, traffic, conversion funnel, and product analytics
- PostgreSQL Row Level Security and secure file storage
- Responsive architecture for Android, iOS, and Web

### 🛒 [ShopPilot Storefront](https://github.com/dominhtri055/shoppilot-storefront)

Customer-facing **Next.js** storefront connected to the ShopPilot ecosystem.

- Public store and product browsing
- Product detail pages and local shopping cart
- Shared Supabase backend
- Storefront analytics event tracking

### 📱 [HireTrack](https://github.com/dominhtri055/HireTrack)

Android application built with **Kotlin and Jetpack Compose** for tracking job applications and organizing the job-search workflow.

### 🍽️ [Restaurant Event App](https://github.com/dominhtri055/restaurant-event-app)

Full-stack restaurant event management application built with **Spring Boot, Thymeleaf, and MySQL**.

### 🚘 [License Plate Assignment API](https://github.com/dominhtri055/COMP9784-87486-Final-Project)

Backend API project using **Node.js, Express, MongoDB, and API-key authentication** to manage VIN-based license plate assignments.
